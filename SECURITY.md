# Security Policy

## Reporting a vulnerability

Please do not report suspected vulnerabilities in public issues or pull requests. Use GitHub's private vulnerability reporting for this repository, if it is enabled: open the repository's **Security** tab and choose **Report a vulnerability**.

There is no separately verified private contact channel. If GitHub private vulnerability reporting is disabled, this project currently has no verified private reporting channel; do not disclose vulnerability details publicly on the assumption that a public issue is private.
